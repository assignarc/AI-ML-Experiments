# W17: Attention Mechanisms and Transformers

> Finally diving into transformers - the thing everyone talks about (turns out they're kind of a big deal)

## What's this?

Learning about **attention mechanisms** and **transformers** - the architecture behind stuff like BERT, GPT, and basically every modern NLP model. Attention lets models focus on the important parts of input instead of treating everything equally (makes a lot of sense when you think about it).

## What's in here

### [HandsOn-MoviewReviews](./HandsOn-MoviewReviews)

Hands-on with transformers using movie review sentiment analysis. Using actual transformer models instead of just GloVe embeddings.

### [NewsArticles](./NewsArticles)

Article categorization using transformers and attention mechanisms. Testing out sentence transformers for multi-class classification.

## Why transformers matter

- **Attention is all you need** - they ditched RNNs and CNNs for sequential data
- Process all tokens at once (parallel processing - way faster than RNNs)
- Can handle long-range dependencies better
- Pre-trained models save ridiculous amounts of time

## What I'm learning

- How attention mechanisms actually work (self-attention is clever)
- Transformers vs RNNs vs CNNs for text
- Using pre-trained transformer models (sentence-transformers, BERT, etc.)
- Why everyone switched to transformers for NLP
