## 🎯 Techniques Covered

### Hierarchical Clustering

- **Agglomerative:** Bottom-up approach
- **Divisive:** Top-down approach (conceptual)
- **Dendrograms:** Tree visualization
- **Linkage Methods:**
  - Single: Minimum distance
  - Complete: Maximum distance
  - Average: Mean distance
  - Ward: Minimize variance

### PCA

- **Dimensionality Reduction:** Reduce features while preserving variance
- **Feature Extraction:** Create new uncorrelated features
- **Visualization:** Project high-D data to 2D/3D
- **Noise Reduction:** Filter out low-variance components
